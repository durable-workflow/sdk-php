# Self-hosted type

Inter 400/500/600, JetBrains Mono 400/500/600 and Space Grotesk 600 implement the One Identity specification. Font files come from the official Google Fonts distribution; the adjacent unmodified OFL licenses cover each family. No font service is contacted at page load.

Official family sources: https://github.com/google/fonts/tree/main/ofl/inter,
https://github.com/google/fonts/tree/main/ofl/jetbrainsmono,
https://github.com/google/fonts/tree/main/ofl/spacegrotesk.
